TEMA 01

JavaScript

El lenguaje que permite dar interactividad a una página web.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite responder a las acciones de los usuarios, actualizar contenido, validar formularios y crear experiencias interactivas.

HTML organiza el contenido, CSS define su apariencia y JavaScript controla gran parte del comportamiento de una página web.

¿Para qué se utiliza?

  • Mostrar u ocultar elementos.
  • Validar formularios.
  • Actualizar información.
  • Crear juegos y aplicaciones web.

Ejemplo práctico

function saludar() {
  document.getElementById("mensajeJS").textContent =
    "¡Hola desde JavaScript!";
}

Pulsa el botón para cambiar este mensaje.

TEMA 02

jQuery

Una biblioteca de JavaScript que simplifica tareas del desarrollo web.

¿Qué es jQuery?

jQuery es una biblioteca que facilita seleccionar elementos HTML, gestionar eventos, modificar contenido y realizar animaciones.

Se reconoce por el uso frecuente de $(). Aunque muchas funciones pueden realizarse con JavaScript moderno, todavía se utiliza en proyectos existentes.

Usos habituales

  • Seleccionar elementos HTML.
  • Responder a clics.
  • Modificar clases CSS.
  • Crear animaciones.

Ejemplo práctico

$("#boton").on("click", function () {
  $("#mensaje").slideToggle();
});

Este mensaje se puede mostrar u ocultar.

TEMA 03

JSON

Un formato de texto ligero para organizar e intercambiar datos.

¿Qué significa JSON?

JSON significa JavaScript Object Notation (Notación de Objetos de JavaScript). Puede utilizarse con muchos lenguajes de programación.

Organiza datos mediante pares de clave y valor. Sus valores pueden ser texto, números, valores booleanos, listas, objetos o null.

¿Dónde se utiliza?

  • Intercambio de datos.
  • Respuestas de APIs.
  • Configuración de aplicaciones.
  • Datos estructurados.

TEMA 04

Web Hosting y dominios

Dos conceptos esenciales para publicar una página web en internet.

¿Qué es el hosting?

El hosting o alojamiento web es un servicio que guarda los archivos de un sitio en un servidor conectado a internet.

¿Qué es un dominio?

El dominio es la dirección fácil de recordar que se escribe en el navegador, por ejemplo misitio.com. El DNS ayuda a relacionar ese nombre con los servidores.

¿Cómo trabajan juntos?

El dominio funciona como la dirección de una casa y el hosting como el lugar donde se guardan sus cosas. Para publicar un sitio, se suben los archivos al alojamiento y se configura el dominio.
