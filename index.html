JavaScript Vanilla

El lenguaje utilizado para agregar comportamiento e interactividad.

¿Qué es JavaScript?

JavaScript es un lenguaje de programación utilizado principalmente para crear páginas web interactivas.

Permite modificar elementos HTML, responder a acciones del usuario, validar formularios, crear efectos y comunicarse con servidores.

HTML, CSS y JavaScript

HTML

Define la estructura de la página y el HTML es el Lenguaje de Marcado de Hipertexto (HyperText Markup Language), el código estándar que se usa para crear y estructurar la estructura básica de las páginas web.

CSS

Define el diseño y apariencia CSS (por sus siglas en inglés, Cascading Style Sheets, o Hojas de Estilo en Cascada) es un lenguaje de diseño que sirve para definir la apariencia visual de los documentos escritos en HTML o XML.

JavaScript

Agrega comportamiento e interacción JavaScript es un lenguaje de programación que se utiliza para dar interactividad, dinamismo y comportamiento a las páginas web.

jQuery

Biblioteca de JavaScript que simplifica tareas comunes del desarrollo web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript creada para simplificar tareas como manipulación del DOM, eventos y efectos visuales.

¿Por qué nació?

Fue creada en una época en la que los navegadores tenían muchas diferencias entre sí. jQuery permitió escribir código más sencillo y compatible.

Sintaxis $ 

$("#menu")

$("#mensaje").fadeIn()

$("#caja").slideToggle()

Ventajas y desventajas

Ventajas

✓ Sintaxis sencilla.

✓ Manipulación fácil del DOM.

✓ Efectos y animaciones.

✓ Fue útil para compatibilidad entre navegadores.

Desventajas

✗ Agrega una dependencia.

✗ JavaScript moderno ya tiene muchas funciones similares.

✗ Puede ser innecesario para proyectos pequeños.

JSON

JavaScript Object Notation.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto utilizado para representar y transportar información.

Es muy utilizado en APIs y aplicaciones web para intercambiar datos entre clientes y servidores.

Estructura de JSON

Clave - Valor 

{
    "nombre": "Innovación Y Tecnología"
}

Array 

[
    "HTML",
    "CSS",
    "JavaScript"
]

Objeto 

{
    "nombre": "Innovación Y Tecnología",
    "activo": true
}

Objeto JavaScript vs JSON

Objeto JavaScript 

const usuario = {

    nombre: "Eli",

    edad: 18

};

Cadena JSON 

{
    "nombre": "Eli",
    "edad": 18
}

Web Hosting y Dominios

Cómo una página web llega a Internet.

¿Qué es Web Hosting?

Web Hosting es el servicio que permite almacenar los archivos de un sitio web en servidores conectados a Internet.

Tipos de Hosting

Hosting Compartido

Varios sitios web comparten recursos de un mismo servidor.

VPS

Un servidor virtual que tiene recursos asignados para un proyecto.

Cloud Hosting

Utiliza recursos distribuidos entre diferentes servidores.

Vercel y proyectos estáticos

Vercel es una plataforma que permite desplegar proyectos web. Puede conectarse con repositorios de GitHub para publicar automáticamente un proyecto.

Dominios

Un dominio es el nombre que una persona utiliza para acceder a un sitio web. 

www.innovación y tecnología.com

TLD

TLD significa Top-Level Domain.

.com → comercial

.net → redes

.org → organizaciones

Subdominio

Un subdominio es una dirección que pertenece a un dominio principal. 

blog.novatech.com
